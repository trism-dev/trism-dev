The name has a hard shadow without blur; weather cycles line up at the loop boundary. Daily project refreshes do not render artwork.

## Latest projects

Run `node scripts/refresh.mjs` for a complete public repository scan. The generator fetches all pages from GitHub's public user-repositories endpoint and validates public links and push timestamps. It shows up to three public owned repositories ordered by `pushed_at` descending, excluding forks, archived repositories, this profile and `lore-tool-pages`. Repositories without a code push are excluded. Featured projects remain eligible. Each entry is only a repository-name button: no description, language or stack.

Pushing code to an older repository moves it ahead of repositories with older pushes. Repository creation dates, metadata edits and first-public discovery do not control order. The old discovery registry is no longer needed. A failed or incomplete scan changes neither README nor plaques; an unchanged result makes no commit.

The Profile workflow runs checks on pull requests and relevant source pushes. On main it refreshes after relevant pushes, on manual dispatch, and daily at 09:17 UTC. Edits in other repositories appear at the next daily or manual refresh. Only the refresh job has content-write permission, and its commit is limited to `README.md` and the three `assets/latest-*.svg` slots. Slots update with their projects; unused slots are cleared. No PAT, external scheduler or keepalive is used. GitHub may delay scheduled runs and disables scheduled workflows after 60 days without repository activity; re-enable the workflow and run it manually if needed.

Sources: [public repository API](https://docs.github.com/en/rest/repos/repos#list-repositories-for-a-user), [scheduled workflow behavior](https://docs.github.com/en/actions/reference/workflows-and-actions/events-that-trigger-workflows#schedule), [workflow inactivity](https://docs.github.com/en/actions/how-tos/manage-workflow-runs/disable-and-enable-workflows), [image motion preferences](https://docs.github.com/en/account-and-profile/how-tos/account-settings/managing-accessibility-settings).
